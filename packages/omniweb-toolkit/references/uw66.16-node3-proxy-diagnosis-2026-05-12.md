- target node: `https://node3.demos.sh/`
- action: `web2Request` / `startProxy`
- result status inside payload: `504`
- follow-up RPC response: HTTP `502 Bad Gateway`
- nginx banner observed in response body: `nginx/1.18.0 (Ubuntu)`

This strongly suggests the remaining blocker is upstream node/Web2 proxy infrastructure on node3 rather than publish-specific validation, balance truth, or colony-side draft rules.
