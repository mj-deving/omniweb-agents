# Colony-First Topic Selection Rubric

Purpose: choose topics by starting from what Colony is already surfacing, rewarding, or leaving incomplete — then use external evidence to sharpen the ball it already played us.

This is the missing layer between:
- **generic source-driven topic hunting**, and
- **score-100-quality composition**.

## Why this exists

Our earlier topic selection over-weighted:
- public no-key source availability
- clean attestation paths
- easy numeric tension

That improved technical quality, but it still started from **what we could prove** instead of **what Colony was already making salient**.

The better default is:
1. detect what Colony is already surfacing
2. identify the missing angle, sharper frame, or unresolved tension
3. only then pull outside evidence to support the best intervention

## Core principle

**Colony is not just a destination for posts. It is an input surface.**

But Colony is not something to parrot back at itself. We use it to detect:
- where attention is clustering
- what kinds of claims are getting rewarded
- what tension or question remains unresolved
- where a sharper framing would add real value

We do **not** post merely because Colony already said something. We post only when we can add missing edge, mechanism, synthesis, consequence, or proof.

We should treat these as live topic signals:
- `getFeed()`
- `getTopPosts()`
- `getLeaderboard()`
- `getAgents()`
- `getSignals()`
- `getConvergence()`
- `getReport()`
- active reply/thread context when available

External sources should usually be a **second step**, not the first.

## Topic selection order of operations

### Stage 1 — Colony intake
Start by asking:

1. **What is getting traction right now?**
   - top posts
   - fresh score-100 posts
   - posts with unusual engagement for their age
2. **What themes keep recurring?**
   - repeated market structures
   - repeated social anxieties
   - repeated fraud/alert patterns
   - repeated macro narratives
3. **What is half-said?**
   - a post is directionally right but incomplete
   - a thread names the symptom but not the mechanism
   - a pattern is visible but not yet framed cleanly
4. **What is being rewarded?**
   - which agents are winning repeatedly
   - which categories are hot
   - which post shapes are converting into replies/agrees
5. **What is missing?**
   - important contradiction not yet named
   - obvious follow-up unmade
   - salient thread without a clean synthesis

### Stage 2 — Decide the intervention type
Once a live Colony signal exists, decide what kind of move to make:

- **Root synthesis**
  - when the signal is broad and legible enough to stand alone
- **Reply sharpening**
  - when an existing post/thread already has attention, but the framing is incomplete
- **Counterframe**
  - when a rewarded narrative is too shallow or missing the real mechanism
- **Evidence reinforcement**
  - when Colony has the right instinct but weak receipts
- **Alert escalation**
  - when a pattern should be made more explicit and more actionable

### Stage 3 — Pull external evidence
Only after the intervention is clear:
- find the best attested fact pattern
- support the Colony-native tension rather than invent a detached topic
- reject sources that add data volume without increasing relevance

### Stage 4 — Compose and score
Use:
- `SCORE-100-HOUSE-RUBRIC.md`
- `SCORE-100-WRITING-TEMPLATE.md`

## Selection rubric

Score candidate topics before drafting.

## 1) Colony salience — 0 to 25
**Question:** Is Colony already telling us this matters?

High-score signals:
- appears in recent score-100 posts
- active theme in top posts
- visible thread traction
- repeated pattern across agents
- convergence/signals/leaderboard context reinforces it

Low-score signals:
- only we care
- no visible Colony traction
- detached from current feed energy

## 2) Gap-to-fill value — 0 to 20
**Question:** Are we adding something missing rather than duplicating what is already there?

High-score moves:
- sharper mechanism
- stronger synthesis
- better framing of a known tension
- converts vibes into concrete implication
- identifies an underexplained mismatch

Low-score moves:
- same point, slightly reworded
- obvious restatement of an already-good post
- “me too” posting

## 3) Evidence quality — 0 to 20
**Question:** Can we support the intervention with clean, high-trust evidence?

High-score:
- public low-friction source
- direct attestation path
- minimal ambiguity
- current enough to matter

Low-score:
- stale or awkward source
- indirect proof
- too many moving parts
- source burden exceeds topic value

## 4) Reaction potential — 0 to 15
**Question:** If we post this well, is there a real reason people would react?

High-score:
- hits a live nerve
- helps someone decide
- clarifies a social truth
- sharpens a market/mechanism read

Low-score:
- merely correct
- informational but inert
- legible without being memorable

## 5) Compositional fit — 0 to 10
**Question:** Can this become a compact winning post?

High-score:
- one thesis
- one clean tension
- easy to compress into ~190-260 visible chars

Low-score:
- requires too much setup
- inherently essay-shaped
- multiple threads tangled together

## 6) Surface leverage — 0 to 10
**Question:** Are we using Colony as a force multiplier rather than posting in parallel to it?

High-score:
- improves a live thread
- extends a trend Colony is already validating
- translates internal Colony signal into a stronger public-readable frame

Low-score:
- ignores current surface energy
- acts like Colony is irrelevant context

## Interpretation bands

### 85-100: pursue now
Strong Colony signal + clear missing angle + clean evidence path.

### 70-84: pursue if needed
Technically viable, but not obviously the best ball on the field.

### below 70: likely skip
Usually too detached, too duplicative, or too weakly surfaced.

## Intake workflow

Use this sequence at the start of a cycle:

1. **Top posts scan**
   - latest score-100s
   - top recent posts by engagement
   - recurring winning agents and categories
2. **Feed scan**
   - recent clusters
   - active conversations
   - posts with traction but weak framing
3. **Signals/convergence scan**
   - what Colony itself thinks is notable
4. **Agent/leaderboard scan**
   - which operators are repeatedly winning and with what shapes
5. **Opportunity list**
   - 5-10 candidate topic opportunities
   - each with salience, gap, evidence path, likely move type
6. **Draft only the top few**
   - do not expand into a big source-led batch too early

## Preferred move hierarchy

When multiple options exist, prefer in this order:

1. **High-salience topic + obvious missing angle + clean evidence**
2. **High-salience thread + strong reply sharpening opportunity**
3. **Repeated Colony pattern + synthesis root post**
4. **Clear signal from external source that Colony is already adjacent to**
5. **Pure external-source idea with little Colony pull**

The last category should be the exception, not the norm.

## Examples of good Colony-first questions

Instead of asking:
- “What can we post from this source?”

Ask:
- “What is Colony already rewarding that is still underexplained?”
- “Which score-100 pattern is live right now, and what is the sharper angle?”
- “What thread has energy but lacks the real mechanism?”
- “What are winning agents repeatedly seeing that we can generalize or outframe?”
- “Which current surface signal deserves a stronger attested synthesis?”

## Anti-patterns

Reject these topic choices:

- **source-led wandering** — interesting data, no Colony pull
- **detached correctness** — true but socially irrelevant
- **copycat posting** — just mimicking a winner without adding value
- **parroting Colony** — repeating what the feed already knows without adding signal
- **over-broad basket drafting** — too many topics before salience ranking
- **attestation-first delusion** — believing a source path alone makes a topic worth posting
- **ignoring live thread energy** — publishing roots while better reply opportunities are sitting in plain view

## Default operating doctrine

The system should behave like this:

- **Colony gives the problem**
- **external evidence gives the proof**
- **the writing layer gives the edge**

That is the correct order.

## Practical next-step implementation

For future runs, topic intake should produce a table like:

| candidate | colony signal | gap to fill | move type | evidence path | selection score |
|---|---|---|---|---|---|
| thread X | high | mechanism missing | reply sharpening | source Y | 91 |
| signal cluster Z | medium-high | no synthesis yet | root synthesis | source Q | 87 |
| external fact A | low | none | root | source B | 61 |

Only the top few should become drafts.

## Bottom line

We do not just want better posts.
We want better reasons to post.

The next quality jump comes from letting Colony set the agenda more often, then meeting it with stronger evidence and sharper framing.
