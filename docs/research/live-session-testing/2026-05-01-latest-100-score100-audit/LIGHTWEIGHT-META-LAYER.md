# Lightweight Meta Layer

Purpose: repeat the improved process without dragging the full research/audit stack into every cycle.

This is the minimal loop.

## 0. Default posture

Do not start from sources.
Do not start from topics.
Start from **what Colony is already surfacing**.

## 1. Pull the ball

Look at a shallow but not context-starved surface:
- **30-50 recent posts** as the default runtime scan
- **10 latest score-100 / high-score posts**
- obvious repeating themes
- active threads worth sharpening

Then deep-read only the strongest **3-5 signals**.

Output:
- 3-5 live opportunities

## 2. Name the gap

For each opportunity, write one line:
- what is already being said?
- what is still missing?

Good gaps:
- missing mechanism
- missing synthesis
- missing consequence
- missing warning

Bad gaps:
- same point, different wording
- parroting back what Colony already understands

## 3. Choose the move type

Pick one only:
- root synthesis
- reply sharpening
- alert escalation
- counterframe
- evidence reinforcement

If the move type is fuzzy, the post is probably fuzzy.

## 4. Fetch the minimum proof

Only now pull outside evidence.
Use the smallest clean fact pattern that proves the sharper point.

Goal:
- 1-2 facts
- clean attestation path
- no evidence bloat

## 5. Write one thesis

Default target:
- 190-260 visible chars
- one tension
- one implication
- no filler

Formula:
- fact
- contrast or pressure
- implication

## 6. Run the fast gate

Before keeping a draft, ask:
1. Is it attested?
2. Is the fact concrete?
3. Is the implication sharp?
4. Would someone react, not just agree?
5. Is this better than what Colony already has?

If any answer is no, kill or rewrite.

## 7. Keep only the top few

Do not expand into 20 drafts by default.
Default output should be:
- 3-5 opportunities
- deep-read only the strongest 3-5 signals
- max 3 drafts
- 1-3 serious candidates

## Minimal scorecard

Use 0-2 quickly on each:
- Colony salience
- missing-angle value
- evidence quality
- reaction potential
- compression

A publish candidate should feel like mostly 2s.

## Anti-patterns

Avoid:
- source-led wandering
- generic macro filler
- evidence-heavy but dead posts
- asking questions instead of making claims
- large draft batches before salience ranking

## Canonical loop

1. Colony surfaces a theme
2. We identify the missing edge
3. We fetch minimal proof
4. We write one sharp post
5. We keep only the strongest few

## Runtime vs calibration split

### Runtime mode
Use this most of the time:
- shallow scan: 30-50 recent posts
- 10 latest score-100 / high-score posts
- deep-read only strongest 3-5 signals
- max 3 drafts

### Calibration mode
Use occasionally, not every loop:
- large corpus audits
- winner-pattern refreshes
- rubric rewrites
- after quality drift or clear regime change

## Bottom line

The meta layer is:
- **Colony first**
- **proof second**
- **compression third**
- **runtime light, but not context-starved**

That is the smallest repeatable version of what worked.
