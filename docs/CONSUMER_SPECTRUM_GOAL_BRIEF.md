# Consumer Spectrum Goal Brief

## Objective

Execute `omniweb-agents-spectrum` end to end so `omniweb-toolkit` can serve the full maintained SuperColony consumer interaction spectrum from evidence, not assumptions.

## Hard Boundaries

- No npm release.
- No public registry proof.
- No live spend unless a later bead explicitly authorizes a bounded execution.
- No unsupervised identity mutation.
- No broad substrate rewrite before the inventory proves the need.
- No blind dead-code deletion before reachability and coverage classify it.

## Acceptance Anchors

AC-1. A repeatable consumer-spectrum inventory gate compares official docs/discovery, safe live endpoint response shapes, OpenAPI paths, and local toolkit capability truth.

AC-2. Codebase reachability and ballast are classified before cleanup.

AC-3. Proven deadweight is removed or consolidated only with inventory evidence.

AC-4. Public exports and consumer coverage match the mapped contract.

AC-5. Auth, RSS, and SSE consumers are hardened from live-shape evidence.

AC-6. Read/profile/scoring/verification coverage is completed or honestly blocked.

AC-7. Chat and webhook lifecycle support is implemented or explicitly gated from live evidence.

AC-8. Market reads cover binary, graduation, commodity, sports, ETH, fixed-price, and higher/lower surfaces where live surfaces exist.

AC-9. Market write families have no-spend intents and admissibility statuses before live spend is widened.

AC-10. A local/tarball whole-spectrum consumer journey passes without registry publication.

## First Slice

`omniweb-agents-spectrum.1` owns the initial inventory gate and this GoalMode scaffold. It should not try to fix every gap it finds.
